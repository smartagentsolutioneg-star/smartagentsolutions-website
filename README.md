## التشغيل والنشر

افتح `index.html` مباشرة أو استخدم خادم ملفات ثابتة. لا يحتاج الموقع إلى تثبيت مكتبات أو خطوة بناء.

للنشر على GitHub Pages:

1. ارفع محتويات هذا المجلد، بما فيها `.github` و`assets`، إلى المستودع المطلوب على فرع `main`.
2. من Settings → Pages اختر GitHub Actions كمصدر للنشر.
3. شغّل Publish website to GitHub Pages من Actions أو ادفع تحديثًا إلى `main`.

الروابط نسبية ومتوافقة مع مستودعات GitHub Pages ذات المسار الفرعي. لا يتطلب الموقع أسرارًا أو مفاتيح وصول.
